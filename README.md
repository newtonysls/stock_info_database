# A股在市股票资料

每只当前在市的沪深京 A 股对应一个目录 `stocks/{股票代码}/stock.md`。股票代码保留前导零，例如 `000001`。本次收录 5578 只。

文档由 `scripts/build_a_share_docs.py` 根据东方财富公开接口的返回值生成。公司简介、经营评述、财务数字、股东、参控股和违规、质押、担保、诉讼记录都来自接口原文或字段，脚本不补写未返回的事实。

在市名单取自行情列表中的沪深京 A 股，不含 B 股。名称含“退市”“定转”或以“退”结尾、尚未给出上市日期，以及没有成交价且没有行业分类的代码已剔除。停牌但仍有行业和市值的股票保留。行情价格和市值对应该次采集时点。

重新生成：

```bash
python3 scripts/build_a_share_docs.py
```

采集缓存写在 `data/cache/`，不纳入版本库。
